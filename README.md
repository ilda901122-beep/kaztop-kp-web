# Kaztop · конструктор коммерческих предложений

Страница для менеджеров Kaztop: заполнили поля, проверили страницы, получили PDF со ссылкой,
отправили руководителю на согласование, после согласования - клиенту. Работает в браузере телефона и компьютера.
Расчёт и PDF делаются на устройстве; общая история КП хранится в Google Таблице и на Google Диске агентства.

## Как пользоваться

1. Откройте страницу, введите пароль (его даёт руководитель). Пароль запоминается на этом устройстве.
2. Заполните: что за помещение, площадь, город, тип помещения, конструкция и толщина, основание и допработы.
   По желанию: вариант для сравнения, цвет RAL, страница с цветами.
3. Нажмите «Собрать КП», пролистайте страницы (обложка с ценой, конструкция, расчёт, условия, смета A4).
4. «Получить PDF» собирает файл и сохраняет его в общую историю. Появляется ссылка на PDF: она открывается
   без пароля, её можно отправить руководителю кнопкой «Отправить руководителю».
5. Нужно поправить (например, толщину): «Изменить» -> поправить -> «Собрать КП» -> «Получить PDF».
   Номер КП остаётся, новый файл становится следующей ред., в истории видно, что изменилось.
6. После согласования: «Поделиться файлом» отправляет PDF клиенту (на телефоне), «Скачать PDF» сохраняет файл,
   «Текст для клиента» копирует короткое сообщение к файлу.

«История» показывает все КП менеджеров: кто, когда, какой расчёт, что менялось, ссылки на PDF всех ред.,
кнопки «Согласовано» и «Отправлено клиенту». Пока общая история не подключена, там видны только КП с этого устройства.

В КП не вписывайте ФИО и телефоны клиента: только компания, объект и город.

## Что внутри

- `index.html`, `ui.js`, `ui.css` - интерфейс и история.
- `app.js` - расчёт и страницы КП (зеркало генератора агентства, сверяется тестами).
- `kp.css` - стили страниц КП, `assets/` - шрифты и фото объектов.
- `data.enc.json` - цены, рецептуры, реквизиты и ключ доступа к истории в зашифрованном виде
  (AES-GCM, ключ из пароля). Без пароля цифры не прочитать; в коде страницы их нет.
- `vendor/` - html2canvas 1.4.1 и jsPDF 3.0.3 (MIT), локальные копии.

## Обновление и публикация

Данные и пароль меняются только пересборкой в репозитории агентства (`tools/build_web.py`), после чего
содержимое папки `web/` публикуется в этот репозиторий (GitHub Pages, ветка `main`, корень).
Страница не индексируется поисковиками (`noindex`), но ссылка открыта: защита - пароль.

## Ограничения

- PDF собирается из картинок страниц (текст в файле не выделяется), файл 1-2 МБ.
- Нужен современный браузер (Safari 15+, Chrome 90+); страница должна открываться по https.
- Если на iPhone вместо файла открылась ссылка вида `blob:`, используйте «Поделиться файлом» или ссылку на PDF из истории.
