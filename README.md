# Kaztop · конструктор коммерческих предложений

Страница для менеджеров Kaztop: заполнили шесть полей, проверили страницы, скачали PDF или сразу отправили
его в WhatsApp. Работает в браузере телефона и компьютера, сервера нет: расчёт и PDF делаются на устройстве.

## Как пользоваться

1. Откройте страницу, введите пароль (его даёт руководитель). Пароль запоминается на этом устройстве.
2. Заполните: что за помещение, компания или объект, площадь, город, тип помещения, конструкция пола.
   По желанию: вариант для сравнения, основание, цвет RAL, страница с цветами.
3. Нажмите «Собрать КП», пролистайте страницы.
4. «Скачать PDF» сохраняет файл, «Отправить в WhatsApp» открывает меню «Поделиться» (на телефоне),
   «Текст сообщения» копирует короткое сообщение к файлу.

В КП не вписывайте ФИО и телефоны клиента: только компания, объект и город.

## Что внутри

- `index.html`, `ui.js`, `ui.css` - интерфейс.
- `app.js` - расчёт и страницы КП (зеркало генератора агентства, сверяется тестами).
- `kp.css` - стили страниц КП, `assets/` - шрифты и фото объектов.
- `data.enc.json` - цены, рецептуры и реквизиты в зашифрованном виде (AES-GCM, ключ из пароля).
  Без пароля цифры не прочитать; в коде страницы их нет.
- `vendor/` - html2canvas 1.4.1 и jsPDF 3.0.3 (MIT), локальные копии.

## Обновление и публикация

Данные и пароль меняются только пересборкой в репозитории агентства (`tools/build_web.py --password …`),
после чего содержимое папки `web/` публикуется в этот репозиторий (GitHub Pages, ветка `main`, корень).
Страница не индексируется поисковиками (`noindex`), но ссылка открыта: защита - пароль.

## Ограничения

- PDF собирается из картинок страниц (текст в файле не выделяется), файл 2-3 МБ.
- Нужен современный браузер (Safari 15+, Chrome 90+); страница должна открываться по https.
