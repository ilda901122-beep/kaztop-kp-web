# Kaztop · конструктор коммерческих предложений

Страница для менеджеров Kaztop: заполнили поля, проверили страницы, получили PDF, отправили руководителю
на согласование, после согласования - клиенту. Работает в браузере телефона и компьютера.
Внешних сервисов нет: расчёт, PDF и история КП - на устройстве, файлы уходят через WhatsApp.

## Как пользоваться

1. Откройте страницу, введите пароль (его даёт руководитель). Пароль запоминается на этом устройстве.
2. Заполните: что за помещение, площадь, город, тип помещения, конструкция и толщина, основание и допработы.
   По желанию: вариант для сравнения, цвет RAL, страница с цветами.
3. Нажмите «Собрать КП», пролистайте страницы (обложка с ценой, конструкция, расчёт, условия, смета A4).
4. «Получить PDF» собирает файл и записывает КП в историю этого устройства.
5. «Отправить руководителю» открывает выбор приложения: WhatsApp, чат руководителя. Текст (номер, объект,
   сумма, что изменилось) уже скопирован: вставьте его подписью к файлу.
6. Нужно поправить (например, толщину): «Изменить» -> поправить -> «Собрать КП» -> «Получить PDF».
   Номер КП остаётся, новый файл становится следующей ред., в тексте руководителю - что изменилось.
7. После согласования «Отправить клиенту» - так же, с коротким сообщением для клиента. «Скачать PDF» сохраняет файл.

«История» показывает КП с этого устройства: когда, какой расчёт, что менялось; «Изменить» собирает новую ред.,
«Таблица» выгружает всё в CSV. Сами PDF хранятся в WhatsApp, куда их отправили.

В КП не вписывайте ФИО и телефоны клиента: только компания, объект и город.

## Что внутри

- `index.html`, `ui.js`, `ui.css` - интерфейс.
- `app.js` - расчёт и страницы КП (зеркало генератора агентства, сверяется тестами).
- `kp.css` - стили страниц КП, `assets/` - шрифты и фото объектов.
- `data.enc.json` - цены, рецептуры и реквизиты в зашифрованном виде (AES-GCM, ключ из пароля).
  Без пароля цифры не прочитать; в коде страницы их нет.
- `vendor/` - html2canvas 1.4.1 и jsPDF 3.0.3 (MIT), локальные копии.

## Обновление и публикация

Данные и пароль меняются только пересборкой в репозитории агентства (`tools/build_web.py`), после чего
содержимое папки `web/` публикуется в этот репозиторий (GitHub Pages, ветка `main`, корень).
Страница не индексируется поисковиками (`noindex`), но ссылка открыта: защита - пароль.

## Ограничения

- PDF собирается из картинок страниц (текст в файле не выделяется), файл до 2 МБ.
- История живёт в браузере устройства: на другом телефоне её нет, очистка данных браузера её стирает, Safari может
  стереть её сам, если страницу не открывать неделю. Для учёта - «Таблица» и файлы в WhatsApp.
- WhatsApp на iPhone может потерять файл, если отправить его вместе с текстом, поэтому файл уходит один,
  а текст копируется в буфер обмена.
- Нужен современный браузер (Safari 15+, Chrome 90+); страница должна открываться по https.
